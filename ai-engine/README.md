# Nujum JO AI Engine

هذا الخادم يربط شاشة الكاميرا بمحرك الذكاء الاصطناعي التجريبي. يستقبل الصورة بصيغة Base64 عبر `POST /analyze` ويرجع النص المستخرج والملخص والنشاط المقترح.

## تشغيل الخادم

من جذر المشروع:

```bash
cd ai-engine
pip install -r requirements.txt
python app.py
```

يعمل الخادم على `http://127.0.0.1:5000`.

## تشغيل الواجهة

في Terminal آخر:

```bash
cd frontend
npm install
npm run dev
```

بعد فتح الواجهة، سجّلي الدخول كطالبة، ثم اضغطي «التقاط وتحليل». ستلتقط شاشة الكاميرا الصورة وترسلها إلى `/analyze` ثم تعرض النص والملخص والنشاط.

## ملاحظة

الاستجابة الحالية تجريبية `mock-analysis` لإثبات التكامل. يمكن لاحقًا استبدال منطق الدالة `analyze_image` بنموذج OCR أو Vision حقيقي مع إبقاء نفس مسار الاتصال.
